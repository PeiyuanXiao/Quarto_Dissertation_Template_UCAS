# Examples

This directory contains example source files converted from real academic writing.

## `quina-article.qmd`

`quina-article.qmd` is a worked example adapted from a Chinese article manuscript on Middle Paleolithic Quina technology in Yunnan and the discussion of Neanderthals in China.

It demonstrates:

- how to move a Word-style academic article into Quarto Markdown;
- how to preserve Chinese headings, abstract, keywords, figure captions, and English summary;
- how to include figures from `thesis/Img/`;
- how to keep numbered in-text references as an intermediate migration step.

This file is not included in the default dissertation render. To use it as a thesis chapter, copy relevant sections into `thesis/index.qmd` and `thesis/chapters/*.qmd`, then register any new chapter files in `thesis/_quarto.yml`.
